## Consortium Role Naming Convention

Each consortium contains exactly 5 peppers, with standardized role labels that indicate their position and purpose in the collection:

| Position | Role Label | Purpose |
|----------|------------|---------|
| 1st | **Anchor** | Milder, foundational pepper that grounds the collection |
| 2nd | **Bridge** | Connects the anchor to the journey ahead |
| 3rd | **Body** | The heart/core of the collection |
| 4th | **Vanguard** | Leads the charge toward intensity |
| 5th | **Flagship** | The crown jewel, always the hottest pepper |

## Display Format

Each pepper's role field follows this format:
```
[Role Label] — [Narrative Description]
```

Example:
```
Anchor — the dried poblano that defines Mexican mole.
Bridge — connecting Mesoamerican origins to the journey ahead.
Body — the heart of this collection, bridging mild and intense.
Vanguard — leading the charge toward the final crescendo.
Flagship — the culmination, where heat reaches its peak.
```

## Implementation Notes

- The 5th pepper (Flagship) must always be the hottest in each consortium
- Role labels appear in bold/emphasized styling in the modal UI
- The narrative portion after the em-dash provides context specific to each pepper's historical/culinary significance
