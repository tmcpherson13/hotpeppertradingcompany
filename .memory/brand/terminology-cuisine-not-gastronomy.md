# Memory: brand/terminology-cuisine-not-gastronomy
Updated: 2026-01-02

All content should use "cuisine" rather than "gastronomy" when referring to food traditions and culinary practices. This rule is enforced in:

1. **AI Synthesis Prompt** (`supabase/functions/pepper-synthesize/index.ts`) - Explicitly instructs the AI to use "cuisine" instead of "gastronomy"
2. **All manual copywriting** - Consortium narratives, historical content, descriptions

## Examples
- "Central to Peruvian cuisine" ✓
- "Central to Peruvian gastronomy" ✗
- "Regional cuisine traditions" ✓
- "Regional gastronomy" ✗
- "Thai cuisine embraces..." ✓
- "Thai gastronomy features..." ✗
